# ADR 0002 — Review before destructive enforcement

Accepted for development preview, 2026-10-06.

Representative multilingual accuracy evaluation is absent. Exact normalized matches are explainable but do not prove semantic abuse. All requested destructive actions downgrade to pending; lossy evasion stays review-grade. Shadow is the initial default and preserves content status after a successfully loaded shadow policy, including subsequent audit failure. An unavailable policy requires review because mode cannot be established.

Original content is never modified for analysis. Normalized offsets cannot be used for masking/redaction without a separately tested original-span mapping. Exceptions suppress only covered occurrences of the specific term. This prevents unrelated safety checks from being disabled.

Hard rejection and account penalties cannot become automatic defaults until representative validation and explicit policy/action handler controls exist.
